CLOCKIN.HUB — READY-TO-RUN WEBSITE

1. Unzip the folder.
2. Open index.html in Chrome/Edge/Firefox.
3. No build step or server is required.

Included:
- Premium responsive streetwear homepage
- Your supplied CLOCKIN.HUB logo
- Your supplied product images
- Product cards + quick-add shopping bag
- Responsive mobile layout
- Newsletter interaction
- Smooth scrolling and hover/motion effects

IMPORTANT FOR REAL LAUNCH:
The checkout is intentionally a demo. Connect your payment/order backend (e.g. Razorpay/Stripe/Shopify/WooCommerce) before accepting payments.

To change prices/products, edit the data-name/data-price attributes in index.html.
To change colors/fonts/layout, edit style.css.
